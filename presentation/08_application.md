# The Application

LungSenseAI isn't just a backend API—it's a fully functional native mobile experience.

- **Real-Time Capture**: Records audio directly from the device.
- **Dynamic Wellness Dashboard**: Tracks BMI, Steps, Hydration, Sleep, and Physical Activity natively.
- **Unified Results**: Presents complex ML probabilities in a clean, user-friendly UI.
- **Exportable PDF Reports**: Allows users to take their history offline via beautifully formatted PDF documents.
