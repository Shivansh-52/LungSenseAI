# LungSense AI

A React Native Android prototype for respiratory sound analysis.

## Features (v0.1.0)
- Record up to 15 seconds of lung sounds.
- Store the recording locally.
- Send the audio to a FastAPI placeholder backend.
- Display a mock prediction (Normal, Crackle, Wheeze, Crackle + Wheeze).
- Clean, medical‑style UI.

## Prerequisites
- **Node.js** (≥ 18) and **npm**
- **React Native CLI** (`npm install -g react-native-cli`)
- **Android Studio** with SDK 33 or later, an emulator or device connected
- **Python** (≥ 3.9) and `pip`

## Setup
### Front‑end (React Native)
```bash
cd LungSenseAI
npm install          # install JS dependencies
npx react-native run-android  # build and launch on Android
```

### Back‑end (FastAPI)
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

The app will call the backend at `http://10.0.2.2:8000` when running on the Android emulator.

## How Audio Flows
1. **HomeScreen** → press *Start Recording* → `RecordingScreen`.
2. `audioService.startRecording()` requests microphone permission, records up to 15 s, and stores the file locally.
3. After recording, user can *Play* the clip or tap *Analyze Sound*.
4. `AnalysisScreen` shows a loading spinner, then calls `api.analyzeAudio(filePath)`.
5. `api.analyzeAudio` sends the file to `/predict`. The FastAPI endpoint returns a dummy JSON payload.
6. The response is passed to `ResultScreen`, which renders a `ResultCard` using the data from `mockPrediction` (or the backend).
