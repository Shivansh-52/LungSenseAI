# LungSenseAI-COPD-v1.0

This directory contains the final frozen COPD disease research model.

## Model Details
- Architecture: CNN + BiLSTM
- Task: COPD vs Non-COPD classification from respiratory audio cycles.
- Preprocessing: 16 kHz Log-Mel Spectrograms.

## Patient-Level Aggregation
- Method: Mean Probability Aggregation
- Threshold: 0.70

## Clinical Disclaimer
This is an AI research prediction based on respiratory audio. It is not a medical diagnosis and has not been clinically validated. A qualified healthcare professional should interpret symptoms and test results.
